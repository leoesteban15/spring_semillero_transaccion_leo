# Proyecto Semilleros: HTML & CSS con Spring Boot

## Sobre el Proyecto
Tomando como referencia el repositorio inicial de semilleros del profesor, le incorporé una estructura para páginas web y la respectiva comunicación con el servidor de SpringBoot en Java.

## Que le añadí
* **Endpoint GET y DELETE de Semilleros**, para listar y ver los semilleros en la base de datos
* **Arquitectura Frontend con HTML y CSS**
